# 🎧 Audio Splitter — Offline Android

تطبيق Android فعلي لتقسيم المحاضرات الصوتية بدون إنترنت بعد تثبيت التطبيق.

## المميزات
- يعمل من **Android 7.0 / API 24** فما فوق.
- اختيار ملفات **MP3 و M4A** من الهاتف.
- الوضع الافتراضي: **10 دقائق + 30 ثانية تداخل**.
- الوضع المخصص: تحديد مدة الجزء والتداخل.
- الوضع الذكي: يختار مدة مناسبة حسب طول المحاضرة.
- كل النتائج بصيغة **MP3**.
- MP3 → MP3 يستخدم `-c:a copy` بدون إعادة ترميز، وبالتالي لا توجد خسارة جودة بسبب التحويل.
- M4A/AAC → MP3 يستخدم `libmp3lame` مع `-q:a 0` لأعلى جودة VBR متاحة.
- المعالجة تتم على الجهاز محليًا؛ لا يتم رفع التسجيل إلى أي خادم.
- لا يحذف الملف الأصلي.
- Progress أثناء إنشاء الأجزاء.
- GitHub Actions جاهز لبناء APK.

## ⚠️ ملاحظة الجودة
تحويل M4A/AAC إلى MP3 ليس Lossless لأن MP3 نفسه ضغط Lossy. لذلك لا يمكن ضمان "عدم فقدان أي جودة" في حالة M4A → MP3. التطبيق يستخدم أعلى جودة VBR عملية (`-q:a 0`). أما MP3 الأصلي فيتم تقسيمه بدون إعادة ترميز.

## مثال التقسيم الافتراضي
```text
01: 00:00 → 10:00
02: 09:30 → 20:00
03: 19:30 → 30:00
04: 29:30 → 40:00
...
```

## البناء
افتح المشروع في Android Studio أو ارفعه إلى GitHub. ملف `.github/workflows/build-apk.yml` سيبني APK تلقائيًا من GitHub Actions.

### FFmpeg
المشروع يستخدم النسخة maintained من FFmpegKit بدل dependency القديمة `com.arthenica:ffmpeg-kit-*` التي تم إيقافها وإزالة artifacts الخاصة بها من Maven Central. النسخة maintained تحافظ على نفس API تقريبًا، لذلك كود التطبيق يظل بسيطًا. 

## الترخيص
راجع تراخيص FFmpeg والـ dependency المستخدمة قبل التوزيع التجاري أو النشر العام.
